# Welcome to your .ημ space

The file sentinel records file changes to an immuatable ledger file``

The ledger is regularly analyzed by statistical analysis
All substantial related changes are automaticly commited with inteligent commit messages

The event ledger is version controled separately from your code

A kanban/ folder was created, and is being populated by a sol agent.
Your existing workflows will be integrated into Rheos by another sol agent.


Your environment was scanned for existing agent runtimes.
opencode, pi, codex, and claude code were configured with hooks to project events to the event leder
As well as a few new tools and skills.

The receipt river requires your agent to add receipts to a decision record at the end of every turn.
So the system will always know why, by what coding agent, and which session, and other meta data

Session Mycology requires your agent to record a self evaluation of the turn,
This way, we know how hard the agent thought the turn was.

Substantially difficult turns require a skill spore to be incubated
If several difficult sessions have a similar pattern of difficulty,
the spore is promoted for use as a general skill.

Occationally, after a statistically significant accumulation of events have been recorded to the ledger
A retrospective agent is dispatched.
It will record lessons, incubate lessons spores, and prune or update misguided mycologically promoted skills
And it will add tasks to the board to suggest infrastructural
changes which it believes could circumvent the issues
encountered in the past entirely.
