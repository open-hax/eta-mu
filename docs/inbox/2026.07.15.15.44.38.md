The frame, settled

It's a new application that uses the legacy CLI as its spec. That sentence is now at the top of the epic's decision record. Nobody "migrates" anything anymore — they open the legacy source as reference behavior, and re-implement the experience in ClojureScript. Same TUI, same tools, same feel. Anything that only existed because of TypeScript mechanics, JSON configs, or TS extensions is dropped without discussion. Your confusion was actually the codebase telling you the truth: the migration framing was wrong, and you were the first one to notice.

Banned words: runtime, core, utils, agent (only eta-mu agent the command survives). packages/runtime gets dissolved, not renamed — its externs duplicate ones packages/eta-mu already has, and its extension runner implements the legacy API you just descoped. There's a new card (dissolve-runtime-package) whose first work item is a consumer audit, so nothing breaks by surprise.
